# Weltverfassung - World Constitution

Eine Verfassung für die Menschheit - A Constitution for Humanity

## Website
- Live: https://worldcodex.space.z.ai

## Features
- 20 Sprachen (Deutsch, Englisch, Spanisch, Französisch, Italienisch, Portugiesisch, Russisch, Chinesisch, Japanisch, Koreanisch, Arabisch, Hindi, Bengalisch, Türkisch, Polnisch, Ukrainisch, Indonesisch, Persisch, Swahili, Vietnamesisch)
- Abstimmungssystem
- Besucherzähler
- Social Sharing (7 Plattformen)
- PDF Download
- Spenden-Button
- Cookie-Consent
- Impressum & Datenschutz

## Deployment

### Netlify
1. ZIP-Datei hochladen oder mit GitHub verbinden
2. Build Command: `npm run build`
3. Publish Directory: `.next`
4. Node Version: 18+

### Lokale Entwicklung
```bash
npm install
npm run dev
```
